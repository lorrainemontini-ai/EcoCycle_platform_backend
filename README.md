# EcoCycle_platform_backend

Backend FastAPI preparado para integração futura com PostgreSQL pela API de dados
do Supabase. As rotas continuam usando os dados simulados originais em memória.
Nenhuma tabela, migração, consulta remota ou alteração de autenticação é executada
ao iniciar a aplicação. A rota de diagnóstico consulta o banco somente quando
chamada. O trabalho foi realizado na branch `feature/supabase`.
